# Паровозики 1.0

Графічна гра в браузері з оригінальною графікою: будуйте колії, перемикайте стрілки й семафори
і проводьте потяги до в'їздів їхнього кольору. Сучасний 3D-вигляд або класична піксельна графіка,
будь-яка роздільність, миша, клавіатура і тач.

## Запуск

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # статична збірка в dist/ (~0,3 МБ gzip), працює з будь-якого каталогу
```

## Керування

| Дія | Миша / клавіатура | Тач |
|---|---|---|
| Перемкнути стрілку чи семафор (режим керування) | ліва кнопка | тап |
| Наступний тип рейки (режим будівництва) | ліва кнопка | тап |
| Збудувати рейку / викликати дрезину-ремонтника | права кнопка | довгий дотик |
| Режим керування ⇄ будівництва | обидві кнопки або `Space` | свайп |
| Швидкість часу ×1 / ×2 / ×3 | `1` `2` `3` | — |
| Пауза (Go! / Save / Bye) | будь-яка інша клавіша або ☰ | ☰ |
| Пункти меню | клік або перша літера пункту | тап |
| Класична графіка / накладання на 3D | `F2` / `F3` | налаштування |

Кнопки внизу праворуч: звук, повний екран, налаштування (ім'я гравця — від нього залежать рекорди і стартовий
рівень; тіні; вигляд; експорт реплею для баг-репорту). Сейви й рекорди зберігаються в браузері.

## Як це влаштовано

```
packages/sim      детермінований симулятор гри (без DOM і реального часу), опційна емуляція
                  відеопам'яті для класичної графіки
packages/render   3D-сцена (Three.js) в оригінальній проекції
packages/app      застосунок: цикл кадру, ввід, звук, інтерфейс, сховище
tools/            еталонна збірка для тестів, генератор трас, витягування таблиць і картинок
tests/            траси, скриншоти, e2e (Playwright)
docs/             відмінності від еталона (fidelity.md), формат трас (trace-format.md)
reference/        еталонна реалізація логіки (submodule), з якою звіряються тести
```

## Тести

```bash
pnpm check          # типи, лінт, юніт-тести
pnpm test:golden    # 92 траси: симулятор = еталон на кожному кроці, сейви побайтно
pnpm oracle:build   # нативна еталонна збірка (clang++) — потрібна для двох наступних
pnpm test:screens   # класична графіка = еталон попіксельно
pnpm replay f.json  # реплей з гри: симулятор і еталон дають однакові траси
pnpm e2e            # Playwright: усі пункти меню, тач, сейви, реплей
pnpm screens        # скриншоти 3D-вигляду в трьох розмірах вікна
pnpm perf           # час кадру: 20 потягів × 5 вагонів
pnpm e2e:dist       # e2e на продакшн-збірці
pnpm test:all       # усе разом
```

Інструменти ставляться локально: Node і pnpm — у `.tools/node`, браузер Playwright — у `.tools/ms-playwright`
(`PLAYWRIGHT_BROWSERS_PATH=.tools/ms-playwright npx playwright install chromium`).
