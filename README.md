# ShortLine Web

Браузерний порт DOS-гри **ShortLine v1.1** (DOKA, 1992, автор — Андрій Снєгов): та сама логіка і
геймплей, сучасна 3D-графіка в оригінальній проекції, будь-яка роздільність, без емуляції DOS.

Основа — реверс-інжиніринг [reSL](https://github.com/konovalov-aleks/reSL) (Олексій Коновалов),
підключений як submodule у `reference/reSL`. Логіку перенесено на TypeScript рядок-у-рядок і
перевірено побітовим порівнянням трас з нативно зібраним reSL («оракулом»).

## Гра

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # статична збірка в dist/ (~0,3 МБ gzip), працює з будь-якого каталогу
```

### Керування

| Дія | Миша / клавіатура | Тач |
|---|---|---|
| Перемкнути стрілку чи семафор (режим керування) | ліва кнопка | тап |
| Наступний тип рейки (режим будівництва) | ліва кнопка | тап |
| Збудувати рейку / викликати сервер (дрезину-ремонтника) | права кнопка | довгий дотик |
| Режим керування ⇄ будівництва | обидві кнопки або `Space` | свайп |
| Швидкість часу ×1 / ×2 / ×3 | `1` `2` `3` | — |
| Пауза (Go! / Save / Bye) | будь-яка інша клавіша або ☰ | ☰ |
| Пункти меню | клік або перша літера пункту | тап |
| Класична графіка / накладання на 3D | `F2` / `F3` | налаштування |

Кнопки внизу праворуч: звук, повний екран, налаштування (ім'я гравця — від нього залежать рекорди і стартовий
рівень, як в оригіналі; тіні; вигляд; **експорт реплею** для баг-репорту).

Сейви й рекорди зберігаються в браузері (IndexedDB), формат файлів побайтно сумісний з оригіналом:
у `Archive` видно і демо-файли гри.

## Як це влаштовано

```
packages/sim      детермінований симулятор (без DOM і реального часу): порт reSL,
                  планувальник корутин на генераторах, віртуальний годинник, ГВЧ Turbo C,
                  опційна емуляція відеопам'яті VGA (класична графіка)
packages/render   Three.js-сцена: ортографічна камера, що повторює проекцію оригіналу
packages/app      Vite-застосунок: цикл кадру, ввід, PC-speaker (WebAudio), HUD, сховище
tools/oracle      патчі до reSL і headless-збірка «оракула», генератор golden-трас
tools/extract     таблиці й картинки з reSL → packages/sim/src/data
tests/            golden-траси, скриншот-тести, e2e (Playwright)
docs/             fidelity.md (відмінності від reSL і DOS), trace-format.md, checklist.md
```

Детальний план — `PLAN.md`; усі свідомі відхилення від reSL (виправлення під DOS-поведінку і
невизначена поведінка оригіналу) — `docs/fidelity.md`.

## Тести

```bash
pnpm check          # типи, лінт, юніт-тести (таблиці, проекція, сейви, U1)
pnpm test:golden    # 92 траси: порт = оракул на кожному кроці, сейви побайтно
pnpm oracle:build   # нативний оракул (clang++, без SDL) — потрібен для двох наступних
pnpm test:screens   # класична графіка = оракул попіксельно
pnpm replay f.json  # реплей з гри: порт і оракул дають однакові траси
pnpm e2e            # Playwright: усі пункти меню, тач, сейви, реплей
pnpm screens        # скриншоти 3D-вигляду в трьох розмірах вікна
pnpm perf           # час кадру: 20 потягів × 5 вагонів
pnpm e2e:dist       # e2e на продакшн-збірці
pnpm test:all       # усе разом
```

Інструменти ставляться локально: Node і pnpm — у `.tools/node`, браузер Playwright — у `.tools/ms-playwright`
(`PLAYWRIGHT_BROWSERS_PATH=.tools/ms-playwright npx playwright install chromium`).
